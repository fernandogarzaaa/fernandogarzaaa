I build local-first AI systems, agent runtimes, LLM orchestration layers, and MCP tooling.

The Chimera ecosystem is the main thread: [OpenChimera](https://github.com/fernandogarzaaa/OpenChimera_v1) is the local-first orchestration runtime, [ChimeraLang](https://pypi.org/project/chimeralang/) defines typed confidence, probabilistic control, and cognition-oriented language primitives, [chimeralang-mcp](https://github.com/fernandogarzaaa/chimeralang-mcp) exposes those primitives as MCP tools, [BETTER-RAG](https://github.com/fernandogarzaaa/BETTER-RAG) is the small grounded retrieval baseline, [GHOST-Chimera](https://github.com/fernandogarzaaa/GHOST-Chimera) is the local agent control plane and trust runtime, and [AXIOM-AETHER](https://github.com/fernandogarzaaa/AXIOM-AETHER) is the Rust Axiom-TTT runtime for fast-weight context adaptation, compression proxying, and MCP access.

PyPI packages: `openchimera` and `chimeralang`.

Currently building: `AXIOM-AETHER`, `GHOST-Chimera`, and `OpenChimera_v1`, with `chimeralang-mcp` tied into the same runtime and toolchain work.

Key repos: [OpenChimera_v1](https://github.com/fernandogarzaaa/OpenChimera_v1), [chimeralang-mcp](https://github.com/fernandogarzaaa/chimeralang-mcp), [BETTER-RAG](https://github.com/fernandogarzaaa/BETTER-RAG), [GHOST-Chimera](https://github.com/fernandogarzaaa/GHOST-Chimera), [AXIOM-AETHER](https://github.com/fernandogarzaaa/AXIOM-AETHER), [Sakay-Naga](https://github.com/fernandogarzaaa/Sakay-Naga).
