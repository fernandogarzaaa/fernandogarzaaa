## 🧭 About Me

I build local-first AI systems with practical control planes for **agent runtimes**, **LLM orchestration**, and **MCP tooling**.
Most of my work is around model routing, retrieval, trust boundaries, local memory, and runtime adaptation.
The goal is software that can run locally, expose clear tool surfaces, and stay inspectable.

## 🧬 The Chimera Ecosystem

[**OpenChimera**](https://github.com/fernandogarzaaa/OpenChimera_v1) - local-first orchestration runtime for models, operator jobs, browser tasks, retrieval, and supervised background jobs.

[**ChimeraLang**](https://pypi.org/project/chimeralang/) - language primitives for typed confidence, probabilistic control, and cognition-oriented programs.

[**chimeralang-mcp**](https://github.com/fernandogarzaaa/chimeralang-mcp) - MCP server that exposes ChimeraLang confidence, hallucination detection, constraints, memory, and runtime tools.

[**BETTER-RAG**](https://github.com/fernandogarzaaa/BETTER-RAG) - local retrieval baseline with hybrid search, grounded answers, citations, and refusal when evidence is weak.

[**GHOST-Chimera**](https://github.com/fernandogarzaaa/GHOST-Chimera) - local agent control plane with Chimera Pilot scheduling, trust runtime, provider routing, and operator workflows.

[**AXIOM-AETHER**](https://github.com/fernandogarzaaa/AXIOM-AETHER) - Rust Axiom-TTT runtime for fast-weight context adaptation, compression proxying, MCP access, and local inference surfaces.
